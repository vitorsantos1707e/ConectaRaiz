# Conecta Raiz

Tecnologia conectando talentos, matérias-primas e oportunidades do Piauí.

# Sobre o projeto

O Conecta Raiz é uma plataforma digital criada para fortalecer o empreendedorismo artesanal do Piauí, conectando artesãos, fornecedores de matéria-prima e consumidores em um único ambiente moderno, acessível e intuitivo.

O projeto surgiu da necessidade de ampliar a presença digital do artesanato regional, valorizando a cultura local através da tecnologia e criando novas oportunidades para pequenos empreendedores.

A plataforma combina:

marketplace artesanal;
busca inteligente de fornecedores;
interação entre usuários;
inteligência artificial;
experiência imersiva com Realidade Aumentada (RA).
Problema

Muitos microempreendedores e artesãos enfrentam desafios que limitam seu crescimento no ambiente digital:

baixa divulgação dos produtos;
pouca presença digital;
dificuldade de conexão com fornecedores;
baixa competitividade em marketplaces tradicionais;
insegurança dos consumidores em compras online.

Mesmo com uma rica produção cultural, muitos produtos artesanais ainda possuem pouca visibilidade no mercado digital.

# Solução

O Conecta Raiz oferece uma plataforma moderna e colaborativa que conecta todos os participantes da cadeia artesanal em um único ecossistema digital.

Principais soluções:
marketplace artesanal regional;
conexão entre artesãos, consumidores e fornecedores;
busca inteligente por categorias e materiais;
visualização de produtos em Realidade Aumentada;
interface moderna e acessível;
fortalecimento da cultura e economia local.

# Execução do projeto
FlutterFlow

O projeto pode ser executado diretamente pela plataforma FlutterFlow através do modo de pré-visualização.

Flutter CLI

Para executar localmente utilizando Flutter:

flutter pub get
flutter run

O aplicativo será iniciado no emulador ou dispositivo conectado.
